# Member 3 — Reports and Project Workspace

Member 3 owns formal report generation and the shared workspace. The report adapter in `backend/startupforge_member3/reports.py` produces editable report content plus DOCX and PDF. It carries source and evidence references, review status, cited statistics, assumptions and unresolved gaps from the selected saved context.

The shared artifact service in `backend/startupforge_member3/core/` records immutable content revisions and file manifests in the project SQLite database, with generated bytes in `member3/backend/data/files/`. Download routes resolve opaque file IDs; clients never provide filesystem paths. Artifacts retain the exact context version and hash that generated them. Editing is optimistic and versioned, and rendering an older content revision never overwrites existing files.

The integrated frontend includes the report editor and download page, project history, and an artifact library. The existing project, job and immutable context APIs remain registered once in the FastAPI host. Member 2 and Member 3 generation APIs use the same saved snapshot and job runner.

Implemented shared routes include:

```text
PATCH /api/v1/projects/{project_id}
GET   /api/v1/projects/{project_id}/contexts
POST  /api/v1/projects/{project_id}/runs
GET   /api/v1/projects/{project_id}/artifacts
GET   /api/v1/artifacts/{artifact_id}
GET   /api/v1/artifacts/{artifact_id}/content
PUT   /api/v1/artifacts/{artifact_id}/content
POST  /api/v1/artifacts/{artifact_id}/renders
GET   /api/v1/files/{file_id}/download
GET   /api/v1/reports/templates
POST  /api/v1/reports/generations
```

Generation and render requests require `Idempotency-Key`. The combined run extracts and analyzes the submitted idea, saves one context version, and starts requested deck, poster and report jobs in parallel. It reports successful and failed child outputs without hiding partial completion.

The shared runtime uses `member1/backend/requirements.txt`; report export needs `python-docx` and `reportlab`. Start the app from the implementation root:

```powershell
.\member1\backend\.venv\Scripts\python.exe -m uvicorn app.main:app --app-dir member1\backend --host 127.0.0.1 --port 8000
```

Shared contracts, the synthetic context fixture and integration details are in `../integration/`.
